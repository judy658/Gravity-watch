# 🎵 Sportify Music — Godot 4.3+ Projesi

## Nasıl Açılır?

1. **Godot 4.3** veya üstünü indir → https://godotengine.org/download
2. Godot'u aç → **Import** → bu klasördeki `project.godot` dosyasını seç
3. **Import & Edit** tıkla
4. Üst çubukta ▶ **Play (F5)** tuşuna bas

## Nasıl Çalışır?

- 64 şarkı listesi yerleşik olarak gelir
- Şarkıya tıkladığında GitHub Releases'dan direkt indirilir ve çalınır
- İndirme bitmeden önce "Yükleniyor..." yazar
- İnternet bağlantısı zorunludur

## Özellikler

| Özellik | Detay |

| 📊 Progress bar | Gerçek zamanlı süre |
| 📱 Mobil uyumlu | 480×854 canvas |

## Gereksinimler

- Godot **4.3** veya **4.4** veya **4.x**
- İnternet bağlantısı (şarkılar GitHub'dan stream edilir)

## Android APK Yapmak İçin

1. Godot editöründe: **Project → Export**
2. **Add Preset → Android** seç
3. Android SDK yolunu ayarla
4. **Export Project** → `.apk` çıktısı alırsın
